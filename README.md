# LINK HUB

Адаптивный каталог ссылок в стиле NEON GLASS. Проект работает без сборки и внешнего сервера.

## Файлы
- `index.html` — структура страницы и форма добавления/редактирования.
- `styles.css` — тёмный неоновый дизайн и адаптивная вёрстка.
- `app.js` — добавление, редактирование, удаление, поиск, фильтры, сортировка, проверка URL, копирование и экспорт JSON.
- `favicon.svg` — значок сайта.

## Запуск на компьютере
1. Распакуй архив.
2. Открой `index.html` в современном браузере.
3. Нажми «Добавить ссылку», введи название и адрес и сохрани.

Для локального тестирования также можно открыть папку через расширение Live Server в VS Code/Cursor.

## Важно о сохранении
Данные хранятся в `localStorage` **конкретного браузера и устройства**. Другие посетители сайта не увидят добавленные тобой ссылки, а их ссылки не появятся у тебя. Это означает, что без сервера нельзя создать общий синхронизированный каталог. Чтобы получить настоящий общий каталог, позже нужно подключить серверную базу данных и правила безопасности.

Перед очисткой данных браузера используй «Экспорт данных», чтобы скачать резервную копию JSON.

## Публикация через GitHub Pages
1. Войди в GitHub и создай новый репозиторий, например `link-hub`. Для простоты выбери **Public**.
2. Загрузи в репозиторий файлы `index.html`, `styles.css`, `app.js`, `favicon.svg` и `README.md` (именно файлы из этой папки, а не ZIP-архив).
3. Открой репозиторий → **Settings** → **Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. В качестве ветки выбери `main`, папку — `/(root)`, затем нажми **Save**.
6. Подожди завершения публикации и открой адрес, который GitHub покажет на странице Pages. Обычно он выглядит как `https://ТВОЙ-ЛОГИН.github.io/link-hub/`.

После изменений загружай обновлённые файлы в репозиторий. GitHub Pages публикует статические файлы, а данные `localStorage` останутся отдельными для каждого браузера.

## Проверка функций
- Добавить сайт с корректным URL.
- Попробовать неверный URL и проверить сообщение об ошибке.
- Отредактировать карточку и удалить её.
- Проверить поиск, категории и сортировку.
- Перезагрузить страницу: записи должны остаться в том же браузере.
- Нажать «Экспорт данных» и проверить скачанный `link-hub-backup.json`.
- Проверить отображение на узком экране.

## Автоматическое сохранение
Ссылки, добавление/редактирование/удаление, импортированные данные и настройки оформления автоматически сохраняются в `localStorage` браузера. При повторном открытии сайта в том же браузере на том же устройстве данные и последние параметры просмотра (поиск, категория и сортировка) восстанавливаются.

Важно: `localStorage` хранится отдельно в каждом браузере и на каждом устройстве. Он не синхронизирует каталог между разными посетителями и не переносится автоматически в другой браузер. Для единого общего каталога всем посетителям нужна облачная база данных и серверная часть.

## Дополнительные функции
- **Избранное** — нажми ☆ на карточке; кнопка «Избранное» переключает отображение избранных сайтов.
- **Случайный сайт** — открывает случайную ссылку из текущего набора результатов.
- **Копировать каталог** — копирует текстовый список сайтов в буфер обмена.
- **История** — хранит до 10 предыдущих состояний каталога и позволяет восстановить выбранное состояние.
- **Экспорт ссылок** — скачивает JSON-файл резервной копии.
- **Сброс оформления** — возвращает стандартные параметры в настройках, не удаляя каталог.
- Расширенные настройки: сила свечения, скругление карточек и эффект фона. Все настройки и данные сохраняются в localStorage этого браузера.

## Language support
The language selector in Settings switches the interface between Russian and English. The selected language is saved in browser localStorage and restored on the next visit. Site names and descriptions entered by users remain unchanged because they are user content.

## Количество колонок
В настройках доступен выбор от 2 до 10 колонок, а также автоматический режим. На широких экранах выбранное число применяется к сетке каталога. На планшетах и телефонах сетка адаптируется к ширине экрана для удобного просмотра. Выбор сохраняется в настройках браузера.
